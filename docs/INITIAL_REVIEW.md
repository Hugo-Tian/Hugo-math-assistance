# 原工程检查与实施记录

检查对象：项目根目录唯一业务文件《高中数学智能学习系统.html》。原文件完整保留，作为设计参考；新入口为 index.html。

| 功能 | 原实现分类 | 检查证据 | 本次实现 |
| --- | --- | --- | --- |
| 侧栏、页面切换、单题即时反馈 | 只有前端交互 | switchTab / checkAns 操作 DOM，正确答案在浏览器常量中 | Vue Router 页面、后端判题 |
| 知识树 | 固定数据且 ID 复用 | treeConfig 的函数性质、单调性、奇偶性、导数计算、极值等都用 func，点击均 openChapter(nd.id) | 14 个独立 ID、章节字段、独立先修边、环路检测 |
| 练习设置 | 只有前端交互 | startPractice 总是从 pQuestions[0] 开始；固定五题，未读筛选设置 | 自定义筛选真实作用于 SQL 查询；自适应逐题重新选择 |
| 搜索 | 固定数据 | renderResults 对每次输入都遍历 sampleResults；关键词直接拼接 innerHTML | 题干关键词匹配 + 知识点 + 难度；Vue 文本转义 |
| 错题本、掌握度、解锁 | 固定展示/未实现闭环 | 判题只改变选项样式；没有持久化和统计更新 | 同一事务保存答题、曝光、掌握度、错题、下一题与推荐 |
| 报告 | 固定数据 | reportData 写死 72%、50% 等 | 根据本人历史记录计算总量、正确率、有效样本与趋势 |
| 注册登录、角色权限、数据库 | 尚未实现 | 无服务端工程、无数据库连接、无用户实体 | Argon2id、服务端令牌与权限、SQLAlchemy + Alembic |
| 视频、拍照、AI 解析 | 占位提示 | alert 提示接入视频/OCR/AI 接口 | 明确标为未开放；本地解析随服务端判题返回 |

原型没有真实服务端业务功能。复用原型的紫色 #534AB7、浅紫 #EEEDFE、浅底 #F8F7FC、侧栏分区和六类业务入口；保留原文件，而非修改它后假称已有数据库能力。

实施阶段：

1. 工程与模型：Vue 3 / Vite / Router / Pinia；FastAPI / SQLAlchemy；Alembic 迁移；MySQL 配置和 SQLite 本地演示。
2. 答题与持久化：所有尝试留存、幂等键、唯一约束、事务写入、答案曝光与复习状态。
3. 自适应算法：最近 20 条平滑正确率、先修 DAG、历史成就、解释性评分、带冷却窗口的难度档位。
4. 页面联动：学生全部入口，管理员知识点编辑、题目版本化编辑/归档、JSON 导入和演示概况。
5. 权限与测试：业务/题库测试、浏览器闭环、MySQL 并发、进程重启。
6. 文档与展示：README、模型算法说明、测试记录、演示脚本、简历文本与真实页面截图。

真实验证发现的修复：MySQL 默认可重复读可能在认证读取后保留旧快照，串行锁之后仍读不到其他请求提交的幂等记录。数据库连接改用 READ COMMITTED，并配合用户行写锁与三组唯一约束；修复后并发重试不再重复计分。浏览器验证发现 select 可访问名称包含选项文本，补充显式 aria-label 后通过。
