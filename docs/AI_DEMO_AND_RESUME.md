# 三分钟演示与简历表述

## 演示前准备

按 README 完成迁移、初始化和真实向量索引。正式展示需先配置服务端 Key 并运行少量真实冒烟验证；当前只验证过独立 Mock 环境，展示时必须先说明“模型输出为测试桩，检索、权限和练习写入为真实应用流程”。演示账号历史为模拟数据。可注册新学生展示干净状态。

## 约三分钟

1. **0:00–0:30** 登录，展示思维导图知识树和保持原样的闯关；选择“导数计算”，点击“向 AI 提问”。说明规则算法负责学习状态，模型负责讲解。
2. **0:30–1:00** 提问“幂函数如何求导，有哪些容易出错的地方？”展示回答公式与引用卡片，点击查看实际检索的自编原文。模型未配置时应展示明确错误，不能冒充正常回答。
3. **1:00–1:35** 创建一道练习并提交错误选项，在反馈页点击“讲解这道题”；展示服务端原题、用户作答和解析上下文。未完成测验期间助手只给一般提示，完成或明确结束测验后再继续讲解。
4. **1:35–2:20** 进入学习助手，选择 Agent 模式，输入“根据我最近的错题，帮我安排三天复习”。展示每天题量、估算时间、先修约束和依据。说明计划还只是草稿，点击“保存计划”，再“开始练习”。
5. **2:20–2:45** 答题后打开报告、错题本并刷新，展示状态来自同一答题记录。切换两个模拟历史账号，比较同目标的确定性推荐，不声称学习效果改善。
6. **2:45–3:00** 管理员展示知识库状态与调试记录；展示评测报告中的真实检索、Mock 和缺 Key 跳过项，解释向量检索未在命中率上胜过关键词基线。

## 可直接使用的四条简历描述

- 基于 Vue 3、FastAPI、SQLAlchemy 迭代高中数学智能学习助手，复用认证、先修 DAG、掌握度与错题闭环，集成多轮对话、上下文讲解及复习计划草稿，保持判题和状态写入由后端控制。
- 实现覆盖 14 个知识点的 42 条自编知识条目，支持 Markdown、TXT、文本 PDF 导入，使用真实中文 BGE Embedding 与持久化 FAISS 索引，加入文档停用过滤、版本兼容检测和检索引用校验。
- 实现模型工具调用协议及六个只读学习工具，使用严格参数校验、服务端身份绑定、调用预算和先修计划校验；通过 Mock 与协议测试验证调用循环、失败处理及幂等保存，真实 LLM API 验收尚待配置密钥。
- 建立 58 条固定评测案例及 JSON/CSV/Markdown 报告脚本，区分调试集与测试集、关键词与向量检索、真实调用与 Mock；新增权限、注入、测验答案防泄露和浏览器联动验证，不将流程通过率表述为模型准确率。
