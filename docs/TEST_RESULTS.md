## 17 项自动化后端/题库测试

1. 全新用户全部知识点未评估、集合冷启动，题目列表与会话当前题不泄露答案/解析。
2. 通关同时要求 5 道不同题目和先修达标；先答后续知识点不能跳过前置条件。
3. 连续错误后推荐具体先修；错题数、报告、树状态和趋势一致；重算恢复相同掌握度。
4. 相同请求及不同键同一题重试不重复保存；同键冲突负载返回 409。
5. 四路并发相同提交仅一条有效计分记录。
6. 跨用户 GET/提交会话返回 403；学生访问管理接口返回 403；无认证报告返回 401。
7. 自定义知识点/难度/数量真实筛选；题量不足提示；关键词检索与 SQL LIKE 通配字符转义有效。
8. 同题答案曝光后的重复练习即使跨日仍不计分；复习记录和错题状态更新。
9. 历史通过后退步，历史时间保持、可用状态保留、当前建议复习。
10. 先修环路拒绝；非法答案与知识点引用导致 JSON 导入整批拒绝，无部分写入。
11. 自适应会话只先派发一题，提交后才选下一题；答对一道不升至高难。
12. 注入中途异常后回滚，不留下半条答题和关联状态。
13. 已通过先修连续答错后，自适应回到先修；固定顺序仍指向后继，确实存在行为差异。
14. 26 条有效记录仅最近 20 条参与计算；难度 1→2→3 后退回基础，符合最少样本与调整间隔。
15. 修改已答题目创建新版本，旧题归档且原判题响应保持不变。
16. 多先修关系和可用状态；无学习目标时相关度统一 0.5；分数范围正确。
17. 140 道题逐题解析实际题干中的参数，以集合交集、函数代入、差商/中心差分、极值条件和区间采样独立核对正确选项；四选项唯一、来源/解析存在、题干不重复。每个知识点 10 题。

## 浏览器场景

1. 注册测试账号后经登录表单进入 → 首页推荐集合 → 自适应答错 → 反馈 33%/1 条有效样本 → 报告 1 次 → 错题 1 条 → 知识树 33% → 点击不同节点打开不同详情 → 查看下一步推荐 → 刷新仍保留数据。
2. demo_foundation 与 demo_advanced 同目标分别得到函数单调性/导数计算推荐；截取两个首页与手机端，检查溢出。
3. 搜索“切线”且难度中等得到 3 题；恶意 HTML 字符串只作为文本显示，无匹配结果；自定义切线中等 10 题如实缩减为 3 题，KaTeX 正常渲染。
4. 管理员先修编辑引入环路被拒绝；非法 JSON 答案被拒绝；实际展示两个演示学生概况；开发服务返回 403 拒绝下载 `data/demo_questions.json` 和 `adaptive_math.db`。

实际修复后重跑相关失败项：select 的可访问名称补充 aria-label；管理员装饰图标标为 aria-hidden。首次测试失败不被隐藏，当前实现已修复。

## MySQL 并发发现与修复

使用本机官方 MySQL 9.5 程序，在项目 `tmp/mysql-verify` 建立独立实例，绑定 127.0.0.1:3307，没有使用或修改现有 3306 服务。验证创建随机命名测试库。默认 REPEATABLE READ 下，并发请求在认证阶段建立的快照可能过期，导致请求等待锁后仍看不到前一事务记录，触发唯一约束。

改为 READ COMMITTED 后，实际执行 5 道题、每题 3 路并发相同提交，总记录数和有效计分均为 5，成功通过集合关卡。迁移差异检查也通过。验证完成后独立实例已关闭，临时数据留在忽略目录，不随代码提交。
